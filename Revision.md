## 1. What the Mandate was built for

The Mandate of Sound Logic (`M1–M10`, `SOURCE` / `COMMAND` / `DERIVATION` / `HYPOTHESIS`) was written to stop agent drift in long coding sessions. Its medium was in-house empirical data: a byte offset the agent can read, a build the agent can re-run, a hash the agent can recompute. In that medium every input is fully quantifiable. A `SOURCE` is a file the program owns; a `COMMAND` is a run the program can repeat bit-for-bit; determinism means byte-identical. The Mandate has succeeded there. The software works.

## 2. How the first edition used it (house cards, dealer rules)

In `SPH-01` and the day's hardening, the program did something the Mandate was not designed for: it extended its own test to the scrutiny of the larger public domain. Outside measurements (MICROSCOPE, PREM, IceCube, Altmann 2001, Dales 1964, RRUFF, the nautilus literature) were admitted into the ledger and allowed to act as **verdicts** on the program's claims. The program gave academia the benefit of the doubt: a claim that disagreed with a published number was written `CONTRADICTED`, as if that number had the same provenance chain as the program's own runs.

That was the dealer's rules applied to the house's cards. It retained testing-domain integrity, because every one of the program's own numbers still carried its tag, its hash and its pre-registration, and the method caught what it was built to catch:

- a 1,000× arithmetic error in the program's own docket (δg/g printed 5×10⁻¹⁴, computed 4.7×10⁻¹¹);
- a prose/script mismatch in the biological track (3.6×10⁻¹⁰ printed, 2.617×10⁻¹⁰ computed);
- six superseded values still circulating in up to ten files;
- a post-verification document that re-graded a pre-registered null as support, and a later one that wrote a verdict on placeholders;
- and, turned outward, a 550 ppm disagreement among thirteen published measurements of G against claimed uncertainties under 50 ppm.

And under those dealer's rules it still raised serious arguments: the energy gate holding by the same formula in chemistry and biology; bulk geophysical integrals being blind to interfacial structure at the 10⁻⁴ level; the E4 null as the program's own measurement; the ComCat b-value as its own measurement; the two-community evidence structure with the cavity as the only bridge; the claim-ledger method itself as a publishable contribution.

## 3. Why the revised edition narrows the scope

External data cannot be quantified by the program at the same degree of certainty as its own testing data. Not because outside measurements are less accurate in their own medium (MICROSCOPE is more precise than anything the program will run) but because their provenance chain is not the program's: there is no hash the program computed, no pre-registration the program witnessed, no run the program repeated. The Mandate's classes assume that chain. Applying them to data that lacks it gives that data a privilege it has not earned in-house, and in the first edition that privilege was a verdict.

## 4. How the revised edition uses it (our cards, our rules; not applied to others, in respect)

The revised edition applies the Mandate's verdict classes **only to in-house data**. Specifically (`MSL-ADD-01`, rules R17–R19):

| | First edition (`SPH-01`) | Revised edition (`XTR-01` Rev B, `MSL-ADD-01`) |
| :--- | :--- | :--- |
| Scope of the Mandate's verdicts | own data and outside data alike | own data only |
| An outside measurement is | a verdict (`CONTRADICTED` if it disagrees) | a **bar**, `PRIOR-CONSTRAINED(value ± uncertainty, source, medium)`, recorded with its number |
| A claim that disagrees with outside data is | `CONTRADICTED` | `PROPOSED`, with the self-generated test that would clear the bar named beside it |
| `CONTRADICTED` may be written by | anyone's measurement | the program's own pre-registered test, or a `DERIVATION` using no outside data |
| Admission to testing requires | a verdict first | a prediction with a unit and a falsifier, nothing else |
| Exit from testing requires | consistency with the literature | own data, hashed, pre-registered, and an independent verifier |
| Outside data the program agrees with is | `CONSISTENT` | `PRIOR-CONSISTENT`, promoted to `SOURCE`-own the day the program measures it |

"Not applied to others, in respect" means the symmetric half: the program does not grade academia's data by the Mandate either. An outside measurement is neither accepted as a verdict nor rejected as unverified; it is recorded as the bar it is, in the medium it was measured in, and the program's own test is what moves anything. The engineering core keeps its outside anchors as bars it already clears. MICROSCOPE keeps its place as the bar for A1 and for the A2 loophole. Nothing outside is dismissed; nothing outside decides.

## 5. What does not change

Tags on everything (R1). Originals read-only, corrections as new files (R2). No citation from memory; fetched or marked *(not re-fetched)* (R3). Pre-registration before data contact (R4). Symmetry; nulls reported in full (R5). Pinned, seeded, hashed (R6). No human exposure, no weapon design (R8). Prose must equal `COMMAND` (R16). The three derivations that gate without outside data (momentum no-go, dimensional and Kepler gates, Griffith invariance) still gate.
